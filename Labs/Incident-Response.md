Packet-level analysis (step-by-step)
----------------------------------

1) Identify suspicious hosts and flows

```bash
# show top IP pairs and protocols
tshark -r capture.pcap -q -z conv,ip -z conv,tcp -z conv,udp

# list all unique external IPs contacted by internal host 10.1.2.3
tshark -r capture.pcap -Y "ip.src==10.1.2.3 && !(ip.dst==10.0.0.0/8)" -T fields -e ip.dst | sort -u
```

2) Inspect DNS activity (fast indicator of suspicious domain resolution)

```bash
# Extract DNS queries and answers
tshark -r capture.pcap -Y "dns.qry.name" -T fields -e frame.time_epoch -e ip.src -e dns.qry.name -e dns.a | sort -k1n

# A quick count of DNS queries by name
tshark -r capture.pcap -Y "dns.qry.name" -T fields -e dns.qry.name | sort | uniq -c | sort -rn | head
```

3) HTTP(s) inspection

For HTTP (cleartext) flows:

```bash
# List HTTP requests with host and URI
tshark -r capture.pcap -Y http.request -T fields -e frame.number -e frame.time -e ip.src -e ip.dst -e http.host -e http.request.uri -e http.user_agent

# Extract files transferred over HTTP (requires tshark with export-object option) or use Wireshark GUI: File -> Export Objects -> HTTP
tshark -r capture.pcap --export-objects http,./extracted_http
```

For HTTPS you need to rely on metadata (SNI, destinations) or TLS decryption when available (server private keys, or session keys via NSS KEYLOG).

4) Reconstruct TCP streams for suspicious flows

```bash
# show TCP stream indices for suspicious packets (replace <filter>)
tshark -r capture.pcap -Y "ip.addr==SUSPECT_IP && tcp" -T fields -e tcp.stream | sort -n | uniq

# export a particular tcp stream to a file
tshark -r capture.pcap -q -z follow,tcp,raw,0 > stream-0.raw
```

5) Extract files/objects from other protocols

- SMB: use `smbclient` or `tshark --export-objects smb` (if supported) or `s3recon`/custom scripts.
- FTP/TFTP: use `tshark --export-objects ftp,./extracted_ftp` or `tftp` object extraction.

Example: extract files from HTTP and analyze hashes

```bash
find extracted_http -type f -exec sha256sum {} + > extracted_http.hashes
grep -i "malicious" extracted_http.hashes || true
```

Creating a timeline
-------------------

Use Zeek (recommended) to produce rich logs and an event timeline. Zeek translates packet-level events into readable logs (conn.log, dns.log, http.log, notice.log).

```bash
# run zeek on the pcap
zeek -r capture.pcap

# convert zeek conn.log to a CSV-like timeline (timestamp, src, dst, proto, duration, bytes)
cat conn.log | zeek-cut ts id.orig_h id.resp_h proto duration orig_bytes resp_bytes > zeek-timeline.tsv
```

Alternatively, build a minimal timeline with tshark fields:

```bash
tshark -r capture.pcap -T fields -e frame.time_epoch -e ip.src -e ip.dst -e _ws.col.Protocol -e frame.len -E header=y -E separator=',' > tshark-timeline.csv
```

Remediation / Containment steps
-------------------------------

Short-term (immediate):

- Isolate affected hosts from the network (or apply ACLs to block observed malicious IPs/domains).
- Capture full-disk images and memory (if host compromise suspected) for deeper analysis.
- Block IOCs at perimeter (firewall, DNS sinkhole, proxy). Use conservative expiry and monitor for false positives.

Mid-term:

- Patch vulnerable services if the packet evidence shows exploitation.
- Rotate credentials for service accounts and users that show suspicious traffic patterns.

Eradication and Recovery
------------------------

- Remove malicious binaries discovered in extracted artifacts. Validate file hashes against known good copies before removal.
- Rebuild or restore clean images for hosts with evidence of code execution.
- Re-enable services gradually and monitor for reappearance of the same packet-level indicators.

Appendix A — Useful commands and quick cheat sheet
--------------------------------------------------

- Packet summary

```bash

# Number of packets per protocol
tshark -r capture.pcap -q -z proto,tree
```

- Top flows and conversations

```bash
tshark -r capture.pcap -q -z conv,ip -z conv,tcp -z conv,udp
```

- Export objects (HTTP example)

```bash
tshark -r capture.pcap --export-objects "http,./extracted_http"
```

- Get full TCP stream in readable form

```bash
tshark -r capture.pcap -q -z follow,tcp,ascii,5 > stream-5.txt
```

- Use Zeek for richer logs

```bash
zeek -r capture.pcap
ls -1 *.log
```
